# 颜色像素扩散 0.1.0 / Pixel Color Bleed 0.1.0

## 中文

这是 0.1.0 版本的 Photoshop UXP 插件发布说明。

安装方式：

1. 下载 GitHub Release 中的 `pixel-color-bleed-0.1.0.ccx`。
2. 使用 Photoshop 的插件管理安装 `.ccx` 文件。
3. 在“插件”菜单打开“颜色像素扩散”。

主要功能：

- 颜色融合始终开启。
- 色相、饱和度、明度支持滑块和手动输入。
- 自动扩展画布默认关闭。
- 生成像素完全不透明，并放在新的图层中。

## English

This is the Photoshop UXP plugin release for version 0.1.0.

Installation:

1. Download `pixel-color-bleed-0.1.0.ccx` from the GitHub Release.
2. Install the `.ccx` file through Photoshop plugin management.
3. Open `Color Pixel Bleed` from the Plugins menu.

Highlights:

- Color fusion is always enabled.
- Hue, saturation, and lightness support sliders and numeric input.
- Canvas expansion is disabled by default.
- Generated pixels are fully opaque and placed on a new layer.
