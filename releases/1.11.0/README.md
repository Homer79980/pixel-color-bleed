# Pixel Color Bleed 1.11.0

This directory contains the installable Photoshop UXP package for version
1.11.0.

Install `pixel-color-bleed-1.11.0.ccx` through Photoshop's plugin manager.

Highlights:

- Color fusion is always enabled.
- Hue, saturation, and lightness controls support sliders and numeric input.
- Canvas expansion is optional and disabled by default.
- Generated pixels are fully opaque and placed on a new layer.
